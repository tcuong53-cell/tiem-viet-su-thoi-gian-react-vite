# Tiệm Việt Sử Thời Gian

Prototype game mobile React + Vite, lấy cảm hứng từ tiệm cổ Việt Nam, tranh Đông Hồ và sự kiện sông Bạch Đằng.

## Chạy dự án

```bash
npm install
npm run dev
```

Màn hình được ưu tiên cho `390x844` và `430x932`, có bottom navigation cố định và safe-area padding cho iPhone.
